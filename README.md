# 📦 StockFlow - Stok Takip Sistemi

**StockFlow**, işletmelerin ürün ve stok hareketlerini kolayca yönetebilmesi için **ASP.NET Core MVC**, **C#**, **Entity Framework Core** ve **MS SQL Server** teknolojileri kullanılarak geliştirilmiş web tabanlı bir stok takip projesidir.

## 🚀 Kullanılan Teknolojiler

* **Backend:** C#, .NET / ASP.NET Core MVC
* **ORM:** Entity Framework Core (Code-First)
* **Veritabanı:** Microsoft SQL Server (MS SQL / LocalDB)
* **Frontend:** HTML5, CSS3, Bootstrap, Razor Views

## ✨ Özellikler

* Ürün ekleme, silme, güncelleme ve listeleme
* Stok giriş ve çıkış hareketlerinin takibi (`StockMovement`)
* Anlık toplam ürün ve stok miktarı özet ekranı (Dashboard)
